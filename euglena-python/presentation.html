08 — Модель I

Эвгленаның объектілік моделі

model.py
class Euglena:
    def __init__(self, length=52.4, energy=50):
        self.length = length      # мкм
        self.energy = energy      # шартты бірлік

    def feed(self, light: bool):  # миксотрофия
        self.energy += 10 if light else 4

    def swim(self):               # талшықпен жүзу
        self.energy -= 3

    def divide(self):             # бойлай бөліну
        if self.energy >= 80:
            self.energy /= 2
            return Euglena(self.length, self.energy)

cell = Euglena()
for hour in range(5):
    cell.feed(light=True)
    cell.swim()
print(cell.energy)                # 85
child = cell.divide()             # 42.5 + 42.5

classEuglena

  • length : floatұзындығы, мкм
  • energy : floatэнергия қоры
  • feed(light)қоректену
  • swim()жүзу
  • divide()бөліну

энергия: 85

09 — Модель II

Популяция өсуінің математикалық моделі

N(t) = K 1 + K − N0N0 · e−rt
N₀ = 10бастапқы жасуша саны
K = 1000ортаның сыйымдылығы
r = 0.69өсу жылдамдығы (≈ тәулігіне 2 есе)
growth.py
t = np.arange(0, 15)   # тәулік
N = K / (1 + (K - N0) / N0 * np.exp(-r * t))

         color="#3DDC97", edgecolor="white")
