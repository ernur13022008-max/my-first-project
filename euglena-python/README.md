# Эвглена × Python — анимациялы презентация

**Тақырыбы:** Деректерден модельге: Python тілін эвглена мысалында түсіну (деректер, мәліметтер, модельдер, гистограмма)
**Орындаған:** Ернұр Ерланұлы · Бт-25-2К · Ботаника кафедрасы
Академик Е.А. Бөкетов атындағы Қарағанды Ұлттық Зерттеу университеті

## Файлдар
- `presentation.html` — дайын 15 слайдтық анимациялы презентация (браузерде ашылады, интернет тек шрифттер үшін керек).
- `speech.md` — 15 слайдқа арналған ауызша баяндама мәтіні (≈12 минут) және болуы мүмкін сұрақтарға жауаптар.
- `speech-short.pdf` — қысқартылған спич (≈7 минут, 4 бет): басып шығаруға немесе телефоннан оқуға ыңғайлы.
- `prompt.json` — кез келген AI-құралға (Gamma, Canva, Claude, т.б.) беруге арналған толық JSON промпт: дизайн жүйесі, түстер, шрифттар, моушн жүйесі, 15 слайдтың мазмұны, анимация реті, спикер мәтіні.

## Басқару
| Перне | Әрекет |
|---|---|
| → / Space / Enter / тінтуір шерту | келесі слайд |
| ← / Backspace | алдыңғы слайд |
| F | толық экран |
| N | спикер ескертпесі (не айту керек) |
| Home / End | бірінші / соңғы слайд |

Презентациядағы барлық Python коды нақты жұмыс істейді; сандар `seed = 2025` арқылы модельденген оқу деректерінен алынған.
