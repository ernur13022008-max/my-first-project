# Абай Құнанбайұлы — презентация

10 слайдтық презентация. Ақынның өмірі мен мұрасы туралы, анимациялары мен слайд ауысулары бар, шоу түрінде жасалған.

| Файл | Не үшін |
|---|---|
| `Abai_Qunanbaiuly.pptx` | PowerPoint нұсқасы: Morph және Curtains ауысулары, өздігінен жүретін анимациялар, спикер жазбалары |
| `Abai_Qunanbaiuly_show.html` | Браузерде ашылатын шоу-нұсқа. Интернетсіз де жұмыс істейді: барлық сурет пен қаріп файлдың ішінде |
| `images/` | Презентациядағы суреттер: автордың кілемі мен портреті, Wikimedia Commons суреттері |
| `src/` | Бастапқы код: `deck.html` және жинау скрипттері |

## PowerPoint-та көрсету

1. `Abai_Qunanbaiuly.pptx` файлын ашыңыз да, **F5** басыңыз.
2. Бір шерту — келесі слайд. Әр слайдтағы анимациялар өздігінен ойнайды. Анимация жүріп жатқанда шертсеңіз, ол бірден аяқталады. Екінші шерту келесі слайдқа өткізеді.
3. Morph ауысуы PowerPoint 2019, 2021 және Microsoft 365 нұсқаларында жұмыс істейді. Ескі нұсқаларда оның орнына Fade ауысуы өздігінен қосылады.

**Қаріптер туралы.** Барлық мәтін Cormorant Garamond мен Montserrat қаріптерімен жоғары ажыратымдылықта (2x) сурет ретінде салынған. Сондықтан Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І әріптері кез келген компьютерде бірдей әрі анық көрінеді, қаріп орнатудың қажеті жоқ. Слайдтағы мәтінді түзетпекші болсаңыз, `src/deck.html` файлын өзгертіп, `src/build.sh` скриптін іске қосыңыз.

## Қайта жинау

```bash
./src/build.sh
```

Скрипт алдымен `src/deck.html` негізінде HTML-шоуды жинайды. Содан кейін Playwright (Chromium) әр слайдтың қабаттарын 2x ажыратымдылықта суретке түсіреді. Соңында python-pptx сол қабаттардан PowerPoint файлын құрастырып, оған ауысулар мен анимацияларды қосады.
